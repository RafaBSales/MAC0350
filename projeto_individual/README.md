# Introdução
Este é um projeto individual de [MAC0350 (Introdução ao Desenvolvimento de Sistemas de Software)](https://uspdigital.usp.br/jupiterweb/obterDisciplina?sgldis=MAC0350)
que visa explorar os conceitos vistos nas primeiras semanas de aula do curso. O projeto consiste na **criação de um web app simples** que integra o back-end (com FastAPI, HTMX e SQL) e o front-end.

---

## Caderno de Receitas
O web app desenvolvido é um **caderno de receitas**, isto é, um arquivo de receitas que oferece ao usuário certas funções e serviços:

- Adicionar novas receitas (com tags para as receitas);
- Remover receitas;
- Atualizar detalhes das receitas (nome, tags e descrição);
- Buscar por receitas.

O web app conta com uma tela para a **busca**, uma para a **visualização da receita**, uma para a **edição** dos detalhes da receita e outra para a **adição** de uma nova receita.

O aplicativo também conta com uma UI responsiva tanto para dispositivos **Desktop** quanto para **Mobile**.
